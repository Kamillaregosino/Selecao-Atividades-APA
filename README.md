# Seminário para disciplina de Análise e Projeto de Algoritmos

## Tema: Algoritmo Gulosos: Seleção de Atividades

A ideia central do seminário é encontrar o maior subconjunto possível de tarefas que possam ser realizadas sem que seus dados se sobreponham. Para isso, foi feito um estudo sobre os algoritmos gulosos, testes para validar se a solução é viável e ótima.
